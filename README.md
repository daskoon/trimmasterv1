# TrimMaster V1

**TrimMaster** is a high-precision, on-device AR Shaving Guide designed for PC and PWA environments.

## Core Features
- **Real-time Face Tracking**: Powered by MediaPipe Face Mesh (Wasm).
- **Parametric Stencil Overlays**: High-contrast "Laser Guides" that warp and scale to fit your facial landmarks.
- **Privacy First**: All video processing happens locally on your device. No cloud uploads.
- **Native Experience**: Zero-latency 60fps tracking in modern browsers.

## Project Vision
To solve the symmetry problem in beard grooming through "Active Guidance" technology.
